# WebForge

WebForge is an intelligent visual web application builder.

The project is built around a **Project Graph** as the single source of truth for the visual editor, layer tree, file tree, code generation, persistence, and future AI services.

## Foundation

- Visual editor
- Layer and project file trees
- Component system
- Code generation and export
- Intelligent file/folder generation
- Backend/API/database architecture
- Local-first AI assistance
